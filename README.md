## Фундамент запуска

1. `python scripts/prepare_data.py` — извлечь три Parquet из архива организатора в игнорируемую папку `data/`.
2. `docker compose build` — собрать среду Python 3.13 с фиксированными прямыми зависимостями.
3. `docker compose run --rm pipeline` — запустить CLI над `data/`, записать результат в `out/`.

Также доступен локальный запуск: `python -m pip install -r requirements.txt`, затем `python starter.py --data ./data --out ./out`. Сейчас полный запуск не считается результатом решения: аналитика, экспорт и интерфейс выполняются по [плану](docs/PLAN.md). Docker служит основным способом проверки на этой машине; локальная команда сохранена для экспертов без Docker.

Архивы организатора уже присутствуют в `track_data/` по истории Git; распакованные `data/`, `.venv/` и `out/` не добавляются в репозиторий. Рабочий интерфейс после реализации — автономный `report.html`, который будет открываться из `out/` без сервера и сети.
