## Подготовка до показа

До выхода на сцену собрать образ. Raw-архив уже лежит в репозитории, а `prepare` и свежий расчёт запускаются при аудитории в первых 45 секундах. Для этого worktree используется отдельное имя образа и лимит 4 CPU:

```powershell
$env:HACKALEM_IMAGE = 'jigas-ha10-chat2:local'
$env:HACKALEM_CPUS = '4'
docker compose build pipeline
```

После успешной сборки выполнить `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "G:\Tools\DockerCleanup\Docker-Cleanup.ps1" -Automatic`. До показа достаточно проверить доступность Docker Compose и архива; не использовать старые файлы `out/demo/` как доказательство презентационного запуска. Во время показа открывать их только после успешного pipeline и сверить `generated_at` в `validation.json` с текущим прогоном. Свежий legacy `report.html` открывается локально через `file://`. Вне пятиминутного показа можно проверить выпуск командой:

```powershell
docker compose run --rm --entrypoint python pipeline test_contract.py --data /app/data --out /app/out/demo
```

### Команды живого прогона

```powershell
$env:HACKALEM_IMAGE = 'jigas-ha10-chat2:local'
$env:HACKALEM_CPUS = '4'
docker compose run --rm prepare
$timer = [System.Diagnostics.Stopwatch]::StartNew()
docker compose run --rm pipeline --data /app/data --out /app/out/demo
$exitCode = $LASTEXITCODE
$timer.Stop()
"exit={0}; elapsed={1:N3} s" -f $exitCode, $timer.Elapsed.TotalSeconds
```

Стопвотч из этого блока измеряет только расчёт: он включает запуск Compose-контейнера, но не `prepare`, сборку образа, рассказ или действия в браузере. Общий таймер пятиминутного выступления идёт отдельно и включает все пункты таблицы.
