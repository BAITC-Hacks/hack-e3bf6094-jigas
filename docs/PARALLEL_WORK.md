# Параллельная разработка HackAlem AI

Рабочая координация: [доска Trello](https://trello.com/b/6tCEnwZQ/hackathon), затем Git-ветки и handoff в карточке. Текущий код и спецификации всегда сверяются с `origin/main`; карточки могут обновляться параллельно. Одновременное создание HA-15 было согласовано: миграция React — HA-15, объяснения — HA-17, маршруты — HA-16. URL карточек сохранены; при передаче используйте полную ссылку.

## Как занять задачу

1. Откройте `HA-CTX`, актуальные `docs/SPEC.md`, `docs/PRODUCT_SPEC.md`, `docs/PLAN.md` и список задач. Проверьте даты обновления и зависимости. Если Git и Trello расходятся, уточните контракт в карточке и не меняйте формулы наугад.
2. Выберите **одну** доступную, не занятую другим чатом карточку с отдельным результатом и файлам. До кода запишите в её описание: контур/чат, ветку, base SHA, файлы, критерий проверки и следующего получателя. Переместите её в «В работе». Участника Trello не назначайте.
3. Создайте отдельный `git worktree` и уникальную ветку от свежего `origin/main`. Не меняйте `main` напрямую. Если файл уже захвачен другой карточкой, выберите независимую задачу или дождитесь handoff.
4. Через 20–30 минут обновите карточку кратким промежуточным результатом или конкретным блокером. После реализации запушьте **только свою ветку**, запишите commit URL, команды и фактические результаты тестов, риски и следующий шаг. Результат переместите в «На проверке»; «Готово» — после независимого review.
5. Интегратор этого потока принимает ветки в `main` после review и общего Docker/browser прогона. Перед новой работой делайте `git fetch origin` и перечитывайте карточку: другой чат мог обновить контракт.

## Docker в нескольких worktree

`compose.yaml` принимает `HACKALEM_IMAGE` и `HACKALEM_CPUS`. По умолчанию образ `jigas-graph-money:local`, лимит pipeline — 12 CPU. Для одновременной работы задавайте **уникальный образ на worktree** и делите общие 12 логических CPU между запущенными pipeline. Пример PowerShell:

```powershell
$env:HACKALEM_IMAGE = 'jigas-ha10-chat2:local'
$env:HACKALEM_CPUS = '4'
docker compose build pipeline
docker compose run --rm prepare
docker compose run --rm pipeline
```

После **каждой успешной локальной Docker-сборки** выполните `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "G:\Tools\DockerCleanup\Docker-Cleanup.ps1" -Automatic`. Контейнеры и volumes автоматически не чистите. Исходный архив/данные, секреты и generated `data/`/`out/` не добавляйте в коммит сверх уже отслеживаемых файлов.
