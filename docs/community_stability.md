# HA-12.2 — чувствительность членства сообществ

Дата расчёта: 23.09.2026. Карточка: [HA-12.2](https://trello.com/c/v0DHtmC1).

## Результат

На официальном наборе baseline Louvain (`resolution=1`, `seed=42`) точно совпал с членством, которое возвращает production `cluster_nodes`. Для чувствительности изменена только `resolution`: 0.8 и 1.2; seed, веса и входные рёбра оставлены теми же. После каждого запуска несвязные результаты Louvain разделены на связные компоненты так же, как в production.

| Resolution | Все группы, включая isolates | Группы среди nonisolates | ARI к baseline | Узлы со сменившимся членством среди 2 229 nonisolates | Изменённые baseline-группы: число / узлы / размеры групп (min / median / max) |
|---:|---:|---:|---:|---:|---:|
| 0.8 | 83 | 64 | 0.898789 | 1 400 (62.8084%) | 19 / 1 400 / 2 / 53 / 278 |
| 1.0 (baseline) | 89 | 70 | 1.000000 | 0 (0%) | 0 / 0 / — |
| 1.2 | 98 | 79 | 0.947932 | 1 073 (48.1382%) | 11 / 1 073 / 15 / 104 / 278 |

Группа считается изменённой, если её точное множество узлов больше не встречается в сценарии. Число узлов со сменившимся членством проверяется отдельно: для узла сравнивается полный набор узлов его группы, поэтому числовые `cluster_id` между сценариями не сравниваются. Размеры в последнем столбце относятся к изменённым baseline-группам; полный список размеров для каждого сценария скрипт возвращает в JSON.

При `resolution=0.8` изменилось членство 62.8% nonisolates, при `resolution=1.2` — 48.1%. Количество групп само по себе не показывает эту перестройку: ARI и явное число узлов со сменившимися соседями дают сравнение самой разбивки. Результат описывает чувствительность алгоритма, а не AML accuracy, ground truth или доказательство того, что группа является организацией.

## Данные и метод

Использованы официальные Parquet HackAlem за июль 2026. Скрипт перед чтением строго сверяет SHA-256 всех трёх входов с зафиксированными значениями:

| Файл | SHA-256 |
|---|---|
| `nodes.parquet` | `d2a45b0df6e9352832d5fb09839d10b9e23f898156c3bab263b051b31cc0296d` |
| `edges.parquet` | `4e71dde5cd3115bcb26e91202665532ee6581cf8233a9fc8059ea59fb7358a38` |
| `transactions.parquet` | `c30c5317b5439591dde86f2058dc47a3d19b2900c055ded994fe547f6fb7e7da` |

Расчёт переиспользует `hackalem.clusters._undirected_projection`: направленные суммы в целых тиынах объединяются по паре узлов, затем переводятся в KZT; пары добавляются в числовом порядке. Baseline для прямой сверки получен через `cluster_nodes(G)`. Для трёх сценариев запускается Louvain на той же проекции с фиксированным seed 42, затем применяются то же разделение несвязных сообществ и отдельные singleton-группы для isolates. В каждом сценарии скрипт повторяет расчёт и требует идентичного членства.

Сравнение членства исключает 19 isolates из ARI и подсчёта изменённых узлов: они неизменно остаются отдельными singleton-группами. Остальные 2 229 узлов сравниваются по co-membership, независимо от числовых меток групп. Для описательной проверки размера изменённых baseline-групп скрипт также выдаёт их полный отсортированный список.

## Воспроизведение

Команды PowerShell из корня репозитория. Входной архив распаковывается во временную папку и Git не меняется:

```powershell
$envRoot = Join-Path $env:TEMP 'ha12-community-stability'
$venvRoot = Join-Path $env:TEMP 'ha12-community-venv'
New-Item -ItemType Directory -Force -Path $envRoot | Out-Null
Expand-Archive -LiteralPath 'track_data\data (1).zip' -DestinationPath $envRoot -Force
python -m venv $venvRoot
$pythonExe = Join-Path $venvRoot 'Scripts\python.exe'
& $pythonExe -m pip install -r requirements.txt
& $pythonExe -m scripts.evaluate_community_stability --data "$envRoot\data"
& $pythonExe -m scripts.evaluate_community_stability --data "$envRoot\data"
```

Оба полных запуска завершились с одинаковым JSON. Внутри каждого запуска все три членства также были рассчитаны повторно и совпали.

Среда расчёта: Python 3.11.4, NetworkX 3.6.1, pandas 2.2.3, NumPy 2.2.6, pyarrow 25.0.1. Зависимости установлены из `requirements.txt` в изолированное временное виртуальное окружение; версия `pyarrow` указана, поскольку она читает Parquet.

Ключевые проверки скрипта:

- SHA-256 входов совпадают с таблицей выше; неподходящий набор отклоняется.
- baseline resolution 1.0 / seed 42 точно равен `cluster_nodes(G)` по отображению `gid → cluster_id`.
- baseline содержит 89 групп: 70 среди nonisolates и 19 singleton-isolates; перед разделением production Louvain вернул 69 сообществ, одно из которых было несвязным.
- membership каждого разрешения совпадает с повторным запуском на тех же входах.

## Ограничения

Проверены только resolution 0.8, 1.0 и 1.2 при одном фиксированном seed. Расчёт не оценивает чувствительность к seed, полноту наблюдаемых переводов, AML-роли, качество расследования или полезность для эксперта. Версии указаны для исследовательского прогона и не расширяют заявленный диапазон Python для приложения. Вывод относится к этому набору данных и версии библиотек. Изменённое членство — техническое свойство разбиения, а не оценка риска клиента.
