## Определения и воспроизводимость

- **P-top-20:** текущий `priority_score` из релизного `compute_priority`, неокруглённый порядок по убыванию; при равном score — числовой `gid` по возрастанию. Список повторно вычислен и совпал со всеми 20 `gid` из временного `top_nodes.csv`.
- **V-top-20:** те же 2 248 узлов, сортировка по `(in_tiyn + out_tiyn)` по убыванию, при равенстве — числовой `gid` по возрастанию. Это объём активности в наблюдаемом фрагменте, а не баланс и не сумма уникальных денег по людям.
- **Контроль:** кандидаты — все узлы вне объединения P и V; таких 2 217. Строка для seed вычислена как SHA-256 от текста `nodes.parquet:<sha>\nedges.parquet:<sha>\ntransactions.parquet:<sha>` в UTF-8, без завершающего перевода строки. Результат seed — `516d43fa653cffe2c4eec99b97e8efc88c19575b2b13f9fb39aee431cdddd838`. Кандидаты сортируются по SHA-256 от строки `<seed>:<gid>` в UTF-8, затем по числовому `gid`; первые 10 — контроль.
- **Слепые псевдонимы:** дедуплицированная выборка упорядочивается по SHA-256 строки `blind-order:<seed>:<gid>` в UTF-8, затем по числовому `gid`; позиции обозначаются `R01`…`R41`. Ключ псевдоним→`gid` и принадлежность к P/V/control хранить отдельно от материала рецензенту.

Воспроизведение полного выпуска из PowerShell, из корня репозитория; распаковка и CSV идут во временную папку:

```powershell
$evalRoot = Join-Path $env:TEMP 'ha12-eval-replay'
New-Item -ItemType Directory -Force -Path $evalRoot | Out-Null
Expand-Archive -LiteralPath 'track_data\data (1).zip' -DestinationPath $evalRoot -Force
python starter.py --data "$evalRoot\data" --out "$evalRoot\out"
```

Для P использовать `out\top_nodes.csv`. Для V загрузить те же Parquet через `hackalem.validation.load`, выполнить `sanity_check`, `build_graph`, `basic_features`, `enrich_features` и отсортировать все строки по сумме `in_tiyn + out_tiyn`, затем по числовому `gid`. Алгоритм контроля и псевдонимов зафиксирован выше. Расчёт запускает существующие функции выпуска; новый eval-фреймворк не добавлялся.

2. На каждый псевдоним записать: проверяемы ли основания по предъявленным данным (0/1/2/не применимо); корректны ли направление и оговорка о неполноте (0/1/2/не применимо); полезен ли и достаточно ли конкретен следующий запрос (0/1/2/не применимо); комментарий со ссылкой на конкретное поле или отсутствующие данные. ## Комплект HA-12.2

Все три эксперимента используют тот же официальный вход с проверкой SHA-256 и оставляют релизные роли, скор, кластеры и CSV без изменений. На зафиксированном snapshot temporal, structural и combined варианты нового score не были реализованы; поэтому они не сравнивались и результат не делает о них выводов. P1-контекст сам по себе не меняет baseline P. Содержательная экспертная оценка 41 слепой карточки из HA-12.1 по-прежнему не проведена.
