## Результат замера

**Пользовательское время не измерено: 0 из 3 GID.** В первом проходе встроенный браузер для localhost был недоступен: подключение к `iab` вернуло `Browser is not available: iab`; список браузеров показал только Chrome extension backend. В этом проходе UI не открывался и таймер на отдельных GID не запускался.

В существующей записи [проверки выпуска](../validation.md) есть один замер появления canvas — **671 мс**. Это время первого отображения в одном прежнем запуске; оно не измеряет поиск и разбор трёх узлов. Указанные там пять значений Docker run с медианой **5,059 с** относятся к batch-расчёту, а не к задаче пользователя. Ни одно из этих чисел не засчитывается как HA-12.1 task timing.

Для завершения **пользовательского** замера нужен демонстратор или аналитик, который откроет три существующих GID в принятом React UI и измерит время от начала поиска до записи собственной оценки основания, ограничения и следующего запроса данных. Отдельно записать build/source hash, три длительности и компетенцию участника. Машинные задержки открытия карточки из дополнения выше этого не заменяют.
