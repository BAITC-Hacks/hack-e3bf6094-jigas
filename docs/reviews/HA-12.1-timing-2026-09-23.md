Указанные там пять значений Docker run с медианой **5,059 с** относятся к batch-расчёту, а не к задаче пользователя. Ни одно из этих чисел не засчитывается как HA-12.1 task timing.

Для завершения замера нужен доступный localhost-браузер и три фактических открытия в принятом React UI. На каждом открыть существующий GID, зафиксировать время от ввода идентификатора до появления карточки, объяснения и графа, затем записать build/source hash и три длительности.
